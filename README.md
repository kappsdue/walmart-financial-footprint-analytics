# walmart-financial-footprint-analytics
End-to-end data analytics project analyzing Walmart's financial performance and U.S. store expansion (2008–2025) using Python, SEC EDGAR API, and Power BI.

## Overview

- **Data sources:** SEC EDGAR XBRL API (financials), Walmart store-locator data, historical store-count-by-fiscal-year table
- **Pipeline:** Python (pandas) for extraction, cleaning, and merging financial metrics across multiple years
- **Analysis layer:** Power BI with custom DAX measures
- **Output:** 3-dashboard interactive report (Executive Summary, Financial Performance, Store Analytics)
